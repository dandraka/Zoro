# ReplacementCSV class

Takes the explicit replacements of `MaskType.ReplacementList` from a csv file instead of `Map` items, so that a long list can be kept (and changed) outside of the configuration. It must be the only item of `FieldMask.ListOfPossibleReplacements`. The file is read when the masking starts. The csv file name is relative to the current directory, like `MaskConfig.InputFile`. Sample usage: &lt;ReplacementCSV CSVFileName="names.csv" FromFieldName="original" ToFieldName="pseudonym" /&gt;

public class ReplacementCSV : Replacement
