# ListExhaustedAction enumeration

What happens when a `ReplacementList` or `ReplacementQuery` mask has no replacement left for a value.

```csharp
public enum ListExhaustedAction
```

## Values

| name | value | description |
| --- | --- | --- |
| Asterisk | `0` | The value is masked with asterisks (see `FieldMask.Asterisk`). This is the default, so that it is visible in the output that the configuration needs more replacements. |
| Error | `1` | A `ReplacementExhaustedException` is thrown. |
| Reuse | `2` | A replacement that is already used is picked randomly, so two values might share a replacement. |
